ECC-Tools

A small, fast command-line tool in C for integer factorization using Lenstra's elliptic-curve method (ECM), built on GMP and libecm.

View on GitHub Build Usage

What it does

ECC-Tools finds factors of large integers. The elliptic-curve method works well for pulling out small-to-medium prime factors of numbers too big for trial division. It does the curve arithmetic through GMP-ECM (libecm) and handles big numbers with GMP.

  • ecm runs ECM on N and prints one factor. It can run curves on several threads and lets you tune B1, B2, curve count, seed, sigma and other ECM settings.
  • factor splits N again and again until every piece is a probable prime, then prints the full factorization.
  • Quick trial division runs first, so small factors come out at once.
  • A single C11 source file built with CMake. MIT licensed.

Build

On Debian or Ubuntu:

sudo apt-get update
sudo apt-get install -y build-essential cmake pkg-config libgmp-dev libecm-dev
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/ecc-tools --help

CMake looks for gmp.h/libgmp and ecm.h/libecm in the usual system and /usr/local paths.

Usage

ecc-tools ecm <N> [--B1 <float>] [--B2 <num>] [-c|--curves <n>] [--seed <u64>]
              [--threads <n>] [--S <int>] [--k <n>] [--ntt] [--sigma <u64>] [--verbose]
ecc-tools factor <N> [--B1 <float>] [-c|--curves <n>] [--maxsteps <n>]
ecc-tools --help

Examples

Fully factor a semiprime:

$ ./build/ecc-tools factor 1000000016000000063
1000000009 * 1000000007

Find one factor with ECM on 4 threads, using a smaller B1 and more curves:

$ ./build/ecc-tools ecm 1000000016000000063 --B1 50000 -c 200 --threads 4
1000000009

If ecm finds no factor with the given settings, it prints no-factor.
